Learning Linux

Dual-booting Arch Linux on my laptop and configuring my own desktop.

When
Fall 2026 – now
Running on
ASUS ROG Zephyrus G14
Built with
Arch Linux, Hyprland, GRUB, git

I’ve used Linux before on RasPis and an Ubuntu home server, but always headless and for one job at a time. This fall, I installed Arch Linux next to Windows on my laptop to learn it properly. I plan on hopefully using Arch for coding, schoolwork, and browsing, and keeping Windows for Ableton and video editing.

I’m using Claude as a tutor for this project: it explains each command and setting, and its risks, before I change anything, and helps me maintain a field guide of commands and fixes. Part of the goal is learning how to learn with a tool like this.

DiskWindows (BitLocker on) and a 98 GB Arch partition on the same drive, sharing one EFI partition
Filesystembtrfs with separate subvolumes for /, /home, and /var/log, zstd compression

Dual-booting with BitLocker

Before installing, I shrank the Windows partition, disabled Fast Startup, and suspended BitLocker to avoid a recovery lock. GRUB uses a custom three-entry menu (Arch, Windows, firmware setup). Instead of chainloading Windows, the Windows entry sets the firmware’s one-time BootNext option and reboots, so BitLocker never sees a changed boot path. A win command does the same from the shell, and Arch puts itself back first in the boot order whenever it starts.

Debugging the GPU

The hardest problem was a black screen at boot: the Intel GPU drives the displays, but the NVIDIA driver was claiming the console on a GPU with no screen attached. The kernel option nvidia_drm.fbdev=0 fixed it. A second black screen came from forcing a 2560×1440 boot resolution on the 2880×1800 panel. G-Helper’s Eco mode in Windows also powers the NVIDIA card off entirely, hiding it from the Linux driver.

The clock was also four hours behind, since Windows keeps the hardware clock in local time and Linux assumes UTC. I fixed it with network time sync in Arch and a registry setting that switches Windows to UTC.

The desktop

The desktop is built on Hyprland across the laptop screen and an external 1440p monitor, with Waybar, kitty, fuzzel, and mako. hyprlock doubles as the login screen. Harvard’s certificate-based Wi-Fi also took some setup.

I also wrote a theme system: each theme is a folder with a wallpaper and per-app color configs, a current symlink selects one, and a theme script swaps the link and reloads every app at once.

Backups

My dotfiles are tracked in a bare git repo pushed to a private GitHub repository, along with copies of the system files I’ve changed (GRUB, the initramfs config, and autologin). Sign-in tokens and browser data are excluded.

What’s next

A recovery USB, then encrypting the Arch partition with LUKS, then Secure Boot.
